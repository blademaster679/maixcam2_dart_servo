# 双 IMU 长时间零漂、温漂记录与融合

## 记录方式

V1.1 接线与驱动设置见 [README](README.md)。同时记录两颗 IMU 的三轴角速度、三轴加速度和各自芯片温度；标称 200 Hz，±500°/s、±4 g，保持当前滤波配置。测试前记下板卡、上电时间、固定方式、供电和散热状态，整个记录期间不主动改变它们。

```sh
./dual_imu --run --warmup-seconds 0 --seconds 1200 --out runs/thermal01
```

该命令仅记录原始数据，不加载旧零偏，也不使用面向短时稳定标定的 `--stationary-confirmed` 判据。操作者仍需确认静止，分析阶段另行检查运动迹象。自然温度变化不应触发短时标定的 2°C 温度跨度或 3°C 参数温差保护。原有带补偿模式的保护保持不变。

每颗各写一个 CSV。逐样本保存原始 int16 六轴、换算后的 g/°/s、温度、读取开始/结束的主机单调时钟、有效/饱和标志及补偿标志；每秒刷新文件和进度日志。`summary.json` 保存实际采集时长、阶段单调时钟起点、配置读回、传输错误、统计量及资源恢复结果。原始数据不可被去均值或平滑数据覆盖。

- 分析时间：`t = ((host_start_ns + host_end_ns) / 2 - phase_start_ns) / 1e9`。这是读取时刻的估计，不是硬件采样时间戳。
- 两路使用同一主机时钟，但依次轮询，未硬件同步；名义 200 Hz 不等于每路恰好 200 个无遗漏样本。
- BMI `sensor_time` 是 24 位自由运行计数器，不能当作样本序号；跨回绕时需要解包，仍不能凭它恢复未读出的样本。
- ICM 和 BMI 使用各自温度。温度计偏差、芯片自热与封装位置不同，不能把两者温度差直接解释为真实板内温差，也不能当作环境温度。

板卡日历若不正确，用工作站的 `Asia/Shanghai` 日期记录实验时间；时长与积分始终使用板卡单调时钟，不为本实验更改系统时间。

### WSL / SSH 中断后的恢复检查

长时间实验应在板端用独立会话启动有界采集，标准输出重定向到板端文件，并由监督程序保存 PID 和退出码。
本次复测板端目录为 `/root/dual_imu_thermal_20261029_retest01`：

```sh
ssh root@10.11.105.1 'python3 /root/dual_imu_thermal_20261029_retest01/status.py'
```

先检查 `exit.json`、`capture.log` 和 `run/summary.json`，再决定是否需要新一轮；不要因 WSL 关闭就假定板端也停止。
如果采集仍在运行，重新接入监控即可。如果板卡本身掉电或重启，则不能恢复已经丢失的连续时段；保留失败/部分记录，
新建目录重测，并记录新的上电与温度起点。完整验收必须同时核对请求时长、退出码、CSV 和资源恢复，不能只看进程已消失。

## 分析口径

```sh
python3 tools/analyze_dual_imu_thermal.py runs/thermal01 \
  --output reports/my_thermal_analysis --plot
# 可选：--previous-profile path/to/calibration.json，仅作离线旧参数复用比较。
python3 cpp/tests/imu_thermal_analysis_test.py
```

分析器需要 NumPy，绘图另需 Matplotlib。它先核对完整时长、样本数、单调时间、原始整数与物理量换算、CSV 与摘要均值/标准差、无效/饱和样本、总线错误和引脚恢复。随后导出 JSON、5 秒分段 CSV、PNG/PDF 曲线。原始样本全部保留，出现扰动不能删掉后再宣称整段静止通过。

1. **角速度零漂**：报告原始均值；冻结最初 60 秒三轴均值 `b₀`，在后续 1140 秒计算 `ω − b₀`、5 秒均值跨度、末 60 秒减初 60 秒均值、短时标准差和按实际时间间隔的残余积分。静止均值包含固定地球自转投影；这些积分是分量漂移示例，不是经外部姿态真值测得的姿态误差。
2. **加速度漂移**：报告原始三轴、模长、相对初 60 秒各轴变化（mg）、末段变化及短时标准差。静止时加速度计仍测得约 1 g 的重力相关比力；一个任意姿态无法分离三轴 offset、比例误差和重力投影。不能把三轴均值都减到零作为通用加速度标定，也不能把本次记录直接双积分成位置精度。
3. **温度相关性**：用前 600 秒的非重叠 5 秒均值拟合 `y(T)=c+k(T−Tref)`，冻结参数后计算后 600 秒的误差，并与前 600 秒固定均值预测作比较。分别输出 gyro 的 °/s/°C 和 accel 的 mg/°C；加速度截距包含重力。记录验证温度是否超出拟合温区。
4. **结论边界**：训练温度跨度不足 1°C 时标为温度激励不足，这是本工具的分析标志而非厂家指标。即使跨度足够，单次自然升温也会混入随时间变化的零偏、热延迟和机械变化，不能识别温度因果或迟滞。因此拟合始终为探索性结果，不自动生成可部署温补参数。需要多温度平台、升降温循环与独立重启复测后再验收。

短时波动用每个 5 秒窗口内的样本标准差及合并方差描述；不把当前不同硬件滤波带宽下的标准差直接称为器件噪声密度。20 分钟记录也不足以单凭最小值宣称计量级零偏不稳定性或全天漂移性能。

首分钟也单独接受运动筛查。如果首分钟有候选扰动，仍保留冻结参考用于描述读数变化，但不能把它称为通过验收的静止零偏标定。`validated` 仅表示记录完整性；`stationarity_screen` 与 `reference_stationarity_screen` 分别描述全段与参考段的运动筛查，均不证明绝对静止。

## 融合方式

以下是待实现和动态验证的集成方案。本次静止试验没有标定两颗的完整安装旋转矩阵，也没有部署姿态融合。

### 先校准并统一坐标与时刻

为每颗分别建立 `R_i`（传感器坐标到板体坐标）、`S_i`（比例/非正交修正）和温度偏置 `b_i(T_i)`：

```text
ω_i_body = R_i · S_gi · (ω_i_raw − b_gi(T_i))
a_i_body = R_i · S_ai · (a_i_raw − b_ai(T_i))
```

加速度至少进行 +X/−X/+Y/−Y/+Z/−Z 六面标定，必要时使用多姿态拟合；陀螺仪需静止偏置和已知旋转验证。仅用本次一个静止重力向量无法确定绕重力轴的相对旋转，不能据此推导完整 `R_i`。[ST AN4508](https://www.st.com/resource/en/application_note/dm00119044-parameters-and-calibration-of-a-low-g-3-axis-accelerometer-stmicroelectronics.pdf) 给出了六姿态重力参考和矩阵标定方法。

先匹配有效带宽与群延迟，再按共同时间轴处理。离线可在两路重叠时段插值，但不能跨长时间缺口；实时实现可用小延迟缓冲或异步 EKF。用实际 `dt`，不要将两个 CSV 的同一行或固定 `1/200` 当成天然同步。动态应用最终应使用 FIFO/硬件时间戳或同步信号重新验证时序。

两颗安装位置不同，旋转时加速度还会相差刚体项 `α×r + ω×(ω×r)`；高速旋转下应把两颗测量换算到共同参考点，不能把该差异全当作传感器噪声。

### 再融合两颗同类测量

在共同坐标、时刻和带宽下，先处理残余偏置，随后用独立静止/运动验证集估计各自残差协方差 `Σ_i`。若误差近似不相关：

```text
Σ_f = (Σ_1⁻¹ + Σ_2⁻¹)⁻¹
x_f = Σ_f · (Σ_1⁻¹ x_1 + Σ_2⁻¹ x_2)
```

标量形式为 `w_i = (1/σ_i²) / Σ_j(1/σ_j²)`。角速度和加速度分别估计权重，不使用同一权重，也不单凭原始零偏较小就认定噪声更低。若共振、供电或温度引起相关误差，应估计联合协方差并使用含交叉项的模型；简单逆方差公式会过度乐观。

持续监测两路差值、SPI 错误、饱和、温区和时间间隔，异常时降低相应传感器权重或报告降级。只有两路不一致时不能仅凭差值断定哪一颗故障，需要健康标志或外部参考。低频漂移仍需温度标定或外部观测约束，两颗平均不能自动消除共同漂移。

### 最后融合角速度与加速度为姿态

可采用四元数互补滤波（如 Mahony 类）或含陀螺仪偏置状态的误差状态 EKF：角速度用于姿态传播，在可信的低动态区间以加速度方向约束倾斜。加速度接近 1 g 只是必要参考，仍需结合振动、创新残差和运动状态，避免发射/制动/转弯时把线加速度误当重力。

只有可靠静止检测成立时才允许缓慢更新陀螺仪偏置；慢速真实转动不能被学习成零偏。六轴 IMU 的重力约束不能提供绝对航向，双六轴也不会自动消除 yaw 漂移；飞行任务需要视觉、磁场或其他航向/位置参考。先确定板体坐标、重力和比力符号，再在姿态变换后扣除重力计算线加速度。

[x-io Fusion](https://github.com/xioTechnologies/Fusion) 提供了姿态互补反馈、加速度拒绝、轴映射和惯性校准模型的实现参考；这里给出集成方法，不声称本次已验证其动态精度。
