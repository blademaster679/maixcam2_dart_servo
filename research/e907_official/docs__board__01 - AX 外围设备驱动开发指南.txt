│   ├── pinmux 
│   │   ├── AX620Q_DEMO_pinmux.xlsm

1.4 PAD 电压切换 
AX620E 芯片有6 个pad group: G1, G6, G8, G9, G11,G12 支持pad 电压1.8V/3.3V 切换。每个
group 有自己的vdet enable 寄存器，G1, G6, G11 放在G10 的misc_ctrl 寄存器bit[2:0]中，G8, 
G9, G12 放在G8 的misc_ctrl 寄存器bit[2:0]中,defaul 1，默认enable，每个group 有自己的
vdet status(RO)寄存器，在对应group 的vdet_ro 寄存器，通过读此寄存器确认电压状态。0 表
明当前检测电压为：1.8V，1 表明当前检测电压为3.3V，通过配置[ms2,ms1]选择当前group
的电压。 [ms2, ms1] == 2'b11, 1.8V Mode； [ms2, ms1] == 2'b00，3.3V Mode;

1.5 Sleep mode 
Pinmux 支持sleep mode 配置，在系统进入sleep mode 时，支持pin 进入指定的状态 
1.5.1 检查版本是否支持pinmux sleep，有如下两种方法 
a. 0x23040A4 bit[1]是否置1（ax_lookat 0x23040A4） 
b. kernel/linux/linux-xxx/drivers/soc/axera/pinmux/ax_pinmux.c 中是否有实现并引用
ax_pinmux_sleep_mode_en 函数。 
1.5.2 配置pinmux sleep mode 
1. sleep en: 开启pin sleep 支持 
2. sleep_oe/sleep_ie: 配置sleep mode 时，pin 是输入还是输出，sleep_oe 输出，sleep_ie 输
入。 
3. sleep out: 配置sleep mode 时输出高低，1 输出高，0 输出低，需要处于sleep_oe 状态。 
4. sleep_st: 施密特触发器使能，同上文st 
5. sleep_pu/sleep_pd/sleep_ps/sleep_pe，同上文，需要注意sleep mode 时的驱动能力是控制一
组pin，默认驱动能力配置为0，如需修改，需要修改文件kernel/linux/linux-
xxx/drivers/soc/axera/pinmux/ax_pinmux.c 中的宏定义，cdphy tx 和cdphy rx 两组pin 不支持配
置休眠上下拉和驱动能力，仅支持配置输入输出状态。 
#define SLEEP_MODE_DEFAULT_ST   0

2. UART 支持波特率到4000000 bits/s。 
3. UART 支持小数波特率，精度计算公式如下： 
整数部分 = source uart clk / (baud * 16)； 
小数分子部分 = (uart clk % (baud * 16)) * 16 / (baud * 16); //结果四舍五入； 
小数部分 = 小数分子部分 / 16； 
默认的source uart clk 为200M，如下为计算波特率为115200 的精度： 
200000000 / (115200 * 16) = 108； 
((200000000 / (115200 * 16)) * 16) / (115200 * 16) = 8 
8 / 16 = 0.5； 
因此，当source uart clk 为200M 时，分频为108.5； 
|(115200 – (200000000 / (108.5 * 16)))| / 115200 = 0.0064%；

&ax_uart3 {

度，在高于105 度时系统进入中断处理函数，soc_crit 表示高温设置为120 度，表示在120 度
的时候系统就会重启。

24 DDR 带宽限制操作指南 
24.1 操作准备 
各个需要带宽限制功能的驱动模块会在相应device 设备初始化之后调用BW limiter 注册接口
函数，其结果会在/proc/ax_proc/bw_limit/ 下生成与各个驱动模块对应的节点，如下面图例： 
 
24.2 操作过程 
成功创建各个带宽限制功能的proc 节点后，可以使用echo 命令来分别设置相应的读写带宽
限制值，以其中dma 带宽限制功能为例，800 表示800MB，1000 表示 1000MB（1GB） 
echo 800 > /proc/ax_proc/bw_limit/flash_axdma/limiter_val_rd 
echo 1000 > /proc/ax_proc/bw_limit/flash_axdma/limiter_val_wr 
当需要关闭带宽限制功能的时候，可以echo 0 到相应proc 节点，如下示例： 
echo 0 > /proc/ax_proc/bw_limit/flash_axdma/limiter_val_xxx  
24.3 需要注意的问题 
1. 执行echo 命令需要在各个device 设备初始化之后。 
2. npu 的带宽限制只能限制读写的总带宽，不能单独限制读或者写的带宽，所以npu 目录下
只有一个节点limiter_val_sum_rdwr，使用方式同上。

25 I2C SLV 操作指南 
25.1 操作准备 
AX620E SOC 一共有2 个I2C SLV。以内核i2c-slave-eeprom.c 测试代码为例： 
&i2c_slv0 { 
        status = "okay"; 
        #address-cells = <0x1>; 
        #size-cells = <0x0>; 
        i2c_slave_eeprom: i2c_slave_eeprom@55 { 
                compatible = "axera,slave-24c02"; 
                reg = <0x40000055>; 
                status = "okay"; 
        }; 
}; 
&i2c_slv1 { 
        status = "disabled"; 
}; 
如上，从机地址需要把bit30 位置1，从机地址为0x55 时，reg 属性需要填写0x40000055 
25.2 操作示例 
可以参考linux-5.15.73(linux-4.19.125)/drivers/i2c/i2c-slave-eeprom.c。 
25.3 需要注意的问题 
i2c slave 不能区分地址和值，若需要进行地址，值的通信方式时，只能单字节传输，不能连
续传输。
